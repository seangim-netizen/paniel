# 🌿 예수동행일기 웹앱 (Journal with Jesus)

> **"질문에 답해보며 예수동행일기를 작성해 보세요. 어느새 하루를 돌아보게 됩니다."**

위드지저스 미니스트리의 **예수동행일기 17문항 점검 가이드**와 **5대 핵심 묵상 질문**을 기반으로 개발된 반응형 웹 애플리케이션입니다. 매일 주님과의 동행을 손쉽게 점검하고, 통계와 차트를 통해 영적 동행 패턴을 분석하며, 감사제목과 묵상을 은혜롭게 기록할 수 있습니다.

---

## 📱 주요 기능 소개

### 1. ✍️ 데일리 동행 점검 & 일기 작성
- **신앙 지표 바 (Faith Bar)**:
  - 📖 말씀읽기 (장수 증감 -/+)
  - 👁️ 예수님 바라보기 (%) (슬라이더 및 **[🎯 점검기반 자동 추천]** 계산 기능)
  - 🕊️ 순종하기 (%) (슬라이더)
  - ⏱️ 기도 시간 (분 단위 조절)
  - ☀️ 말씀 큐티 (QT 완료 토글)
- **📋 17문항 정밀 점검 가이드**:
  - 1~14번: 일상 순간순간(기상, 식사, 일, 대인관계, 가정, 이동 등) 주님을 생각했는지 원터치 **예 / 아니오** 칩 버튼
  - 15번: 예수님을 몇 분 정도 생각했는지 기록 (+15m, +30m, +60m 퀵 버튼 지원)
  - 16번: 하나님이 하셨다고 고백할 **감사제목 3가지 이상** 기록 (추가/삭제 가능)
  - 17번: 자유롭게 기록하는 동행일기 본문
- **🕊️ 5대 핵심 묵상 가이드**:
  1. 아침에 일어났을 때, 식사 할 때, 일 할 때, 사람 만날 때 예수님을 생각하였습니까?
  2. 성경 통독과 큐티를 통해 주님이 하신 말씀은 무엇이었습니까?
  3. 오늘 하루 중에서 주님이 내게 주신 메시지는 무엇이 있습니까? 예수님이 하라고 지시하시는 것 같아 순종한 일은 무엇입니까?
  4. 말씀을 주신 것들 중에 불순종 했던 것은 무엇입니까?
  5. 감사 기도 3가지를 적어 보십시오.
- **💬 나눔 댓글 불러오기 & 직접 작성 (Fellowship Comments)**:
  - 위드지저스 공식 일기방에 남겨진 형제자매님들의 **따뜻한 댓글(684개+)**을 일기별로 완벽하게 불러와 표시.
  - 앱 안에서 새로운 축복과 격려의 댓글을 즉시 작성하고 관리 가능.
- **📋 나눔 양식 복사 (One-Click Share)**:
  - 작성된 일기를 카카오톡 단체방(주일나눔 온라인1조, 형제방 등)이나 위드지저스 홈페이지에 바로 올릴 수 있는 깔끔한 양식으로 클립보드 복사.

### 2. 📖 66권 전체성경 앱 통합 탑재 (총 9개 역본 & 풀 기능 지원)
- 창세기 1장부터 요한계시록 22장까지 **66권 전체 성경**과 **총 9개 주요 역본**이 앱 내 `📖 전체성경` 전용 탭으로 내장되었습니다.
  - **한국어 역본 (5종)**: `개역개정(KG)`, `새번역(SB)`, `개역한글(KH)`, `쉬운성경(EASY)`, `현대인의 성경(HYUNDAI)`
  - **영어 역본 (4종)**: `NIV`, `NLT`, `NKJV`, `RSV`
- **주요 기능**:
  - **기본 역본 선택**: 9개 역본 중 원하는 역본으로 자유롭게 전환하여 통독
  - **2개 역본 동시 대조 모드**: 1차 역본과 2차 역본(예: 개역개정 vs NIV, 새번역 vs 쉬운성경 등)을 구절별로 나란히 비교
  - **전권/전장 이동 모달**: 구약 39권, 신약 27권의 모든 장을 원터치 그리드로 탐색
  - **고속 성경 검색**: 9개 모든 역본 대상 키워드 검색 (실시간 역본 필터 및 소요 시간 표시)
  - **음성 낭독 (TTS 플레이어)**: 재생/일시정지, 구절 이동, 속도 조절, 반복 재생
  - **1,189장 통독 진도표**: 66권 전체 1,189장에 대한 체크마크 및 완독률(%) 실시간 계산
  - **구절 메모 & 묵상 노트**: 구절별 묵상 기록 및 백업
  - **뷰어 테마 및 글꼴**: 라이트/세피아/다크 모드 및 글자 크기 실시간 조절
- 새 창으로 성경 열기(`target="_blank"`)도 제공.
- *(기존에 만드신 원본 통독앱 폴더는 전혀 건드리지 않고 안전하게 독립 복제 탑재되었습니다)*

### 3. 🔄 위드지저스(jwj.kr) 원클릭 실시간 동기화
- 상단 헤더의 **[🔄 실시간 동기화]** 버튼 또는 설정 화면의 동기화 버튼 클릭 한 번으로 위드지저스 서버(`swgim418 / 김시웅 성도님`)에 접속하여 최신 일기와 나눔 댓글을 실시간으로 가져와 자동 업데이트합니다.
- 총 **210편의 일기 전체**와 **684개의 나눔 댓글**이 완벽하게 동기화되어 있습니다.

### 4. 📅 동행 달력 & 지난 일기 아카이브
- 월간 캘린더에서 작성한 날짜, 당일 예수님 바라보기 % 도트 뱃지, 댓글 개수(💬) 표시
- 원하는 날짜를 클릭하여 언제든 지난 일기와 댓글 열람 및 수정
- 최근 작성한 일기 리스트 뷰 지원

### 5. 📊 동행 통계 & 성찰 리포트 (Chart.js 연동)
- **연속 동행 일수 (Streak 🔥 210일 달성)**: 매일 이어지는 동행의 흔적을 불꽃 뱃지로 축복
- **주님 바라보기 & 순종하기 14일 추이 차트**: 변화하는 영적 온도를 한눈에 파악
- **14개 항목별 상황 분석 차트**:
  - 아침 기상, 식사, 일, 이동, 가정, 대인관계 등 언제 주님을 잘 기억하고 언제 놓치기 쉬운지 분석
- **맞춤형 은혜 조언 (Spiritual Coaching)**:
  - 가장 친밀했던 순간과 주의가 필요한 순간을 도출하여 실천적인 권면 메시지 제공
- 말씀 통독 누적 장수 & 총 기도 시간 막대/선 복합 차트

### 6. 🙏 은혜의 감사함 (Gratitude Stream)
- 매일 고백한 "하나님이 하셨다고 고백할 감사제목" 455개를 한눈에 모아보는 감사 피드
- 지난날 하나님께서 베풀어주신 손길을 묵상하며 감사 회복

### 7. ⚙️ 설정 & 데이터 안전 백업
- **개인정보 완벽 보호**: 데이터는 사용자 브라우저의 `LocalStorage`에 안전하게 보관됩니다.
- **JSON 백업 & 복원**: 새 휴대폰으로 바꾸거나 PC로 옮길 때 백업 파일 하나로 손쉽게 복원 가능.
- **PWA 지원**: 스마트폰 홈 화면에 '앱'으로 바로 추가하여 오프라인에서도 사용 가능.

## 🚀 실행 방법

### 방법 1. 더블 클릭으로 바로 실행 (가장 추천)
- 폴더 내 **`run_app.bat`** 파일을 더블 클릭하면 자동으로 로컬 서버가 시작되고 웹 브라우저가 열립니다.

### 방법 2. 파이썬 터미널 실행
```bash
python server.py
```
브라우저에서 `http://localhost:8080` 으로 접속됩니다.

### 방법 3. 브라우저에서 직접 열기
- `index.html` 파일을 크롬이나 엣지 브라우저로 드래그하거나 더블 클릭하셔도 오프라인으로 바로 작동합니다!

## 📱 스마트폰 홈 화면에 앱(PWA)으로 설치하기
1. 모바일 브라우저로 해당 웹앱을 엽니다.
2. **아이폰 (Safari)**: 하단의 공유 버튼 [↑] 클릭 ➔ **'홈 화면에 추가'** 선택
3. **안드로이드 (Chrome)**: 우측 상단 메뉴 [⋮] 클릭 ➔ **'홈 화면에 추가'** 또는 **'앱 설치'** 선택
4. 스마트폰 홈 화면에 예수동행일기 아이콘이 생성되어 일반 앱처럼 실행됩니다.
